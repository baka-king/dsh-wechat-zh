# 微信遥控 · 固定菜单（模板）

> 用途：在微信里用固定编号指代左侧栏的会话，不用每次翻 `/list`。
> **这份编号只存在于这个文件里** —— DSH 的会话不能改名（标题由第一句话自动生成），
> 所以侧栏上不会显示 1/2/3/4。编号是我和 agent 的约定。

## 编号表

| # | 名称 | 说明 |
|---|---|---|
| 1 | 微信同步 | 微信绑定的那个会话，最常用 |
| 2 | 待办 | 临时任务 |
| 3 | 项目 A | 换成你自己的 |
| 4 | 项目 B | 换成你自己的 |

## 两条命令

### `看 N` —— 看界面，不切会话

```
看 3
```
→ agent 去点左侧栏第 3 项，截图发到微信。
**不改变微信绑定**，当前对话还在原来那个会话。

### `切 N` —— 切换会话

```
切 2
```
→ 等价于 `/switch`，之后微信的消息都进第 2 个会话。

## 维护

- 新增会话就往后加一行，别插队（插队会让旧编号全错）
- 每月清理一次，删掉已经不用的会话
